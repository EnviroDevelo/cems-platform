I/O boards on the network

The I/O boards are on Ethernet. Find lists every board on the network, whatever its IP. Give a new board the board slot it is (Board 1, 2 or 3: its IP and Modbus address are the iob settings); it gets this supervisor's mask and gateway and then talks only to this supervisor.

I/O board addresses

A new I/O board has no address and answers only at 246. Connect one new board at a time, find it, then give it the address of the board it is (Board 1, 2 or 3 below), or any free address.

Serial number

-

The serial number can only be changed with a token from the developer, made for this unit's chip ID and its current serial (so it works once, on this unit), plus a factory login. A parameter backup never changes it. Every change is in the event log.

Alarm actions

What each alarm does when it is raised. Email: sends an email (set up below). Modbus: counts in the common-alarm register for the control system (every alarm's own state is always readable over Modbus). Relay: switches an alarm relay output. No tick: shown here, on the touchscreen and in the event log only. Changes need an admin login.

Alarm relays

Fail-safe: the output is energised while there is no alarm, so a power cut or a fault also signals. A relay output overrides anything the application drives on the same output.

Clock

The instrument keeps the site's local standard time (no daylight saving), so records never jump. Every change of the clock is in the event log.
