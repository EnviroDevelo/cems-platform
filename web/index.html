Instruments

Analysers and other devices the instrument reads over Modbus TCP on the I/O network (it is the master; they answer). RS-485 devices go through a Modbus TCP gateway: the gateway's IP, and the device's address as the unit ID.

Changing instrument settings needs REMOTE (set at the touchscreen) and an admin login.

Register explorer

Reads registers from any device on the I/O network (admin; reads only, nothing is written to the device). Every row shows the words decoded every way: find the one that matches the device's own display, then click it to fill a point.

I/O boards

Green: output on. Blue: input active. Red: fault. Settings are the iob parameters (filter "iob", admin level): sensor types per connector in iobN_temp_type, calibration in iobN_temp_offset and iobN_temp_span, or "Set to" against a reference thermometer.

A new I/O board has no address and answers only at 246. Connect one new board at a time, find it, then give it the address of the board it is (Board 1, 2 or 3 below), or any free address.

Serial number

The serial number can only be changed with a token from the developer, made for this unit's chip ID and its current serial (so it works once, on this unit), plus a factory login. A parameter backup never changes it. Every change is in the event log.

Digital input alarms

Tie any digital input to an alarm. The label becomes the alarm's name everywhere: the alarm list, the touchscreen, the event log, the Modbus map (discrete inputs 7000 + slot) and the Excel handover file. What each one does (email, Modbus common alarm, relays) is set in Alarm actions below, like any alarm. An input with a wire break or on a lost I/O board does not raise its alarm: the slot shows "input unreliable" and the input-fault alarm covers it.

Alarm actions

What each alarm does when it is raised. Email: sends an email (set up below). Modbus: counts in the common-alarm register for the control system (every alarm's own state is always readable over Modbus). Relay: switches an alarm relay output. No tick: shown here, on the touchscreen and in the event log only. Changes need an admin login.

Fail-safe: the output is energised while there is no alarm, so a power cut or a fault also signals. A relay output overrides anything the application drives on the same output.

Clock

The instrument keeps the site's local standard time (no daylight saving), so records never jump. Every change of the clock is in the event log.
