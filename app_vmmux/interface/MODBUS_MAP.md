# CEMS Supervisor Valve Manager / Multiplexor: Modbus register map

Map version 0 (input register 9001), platform block layout 3, core 0.10.0. **Generated by `make modbus-map` from the firmware's tables (`tools/modbus_map.c`); do not edit by hand.** `make test` fails if it no longer matches the firmware: a moved address or a removed value needs a new map version (CIP-14.5).

Addresses are 0-based (protocol addresses). 32-bit values: high word first unless the entry says "low word first". Text and bytes: two bytes per register, first byte in the high half unless it says "low byte first". Input registers 9000-9199 are the platform's block, the same in every product.
